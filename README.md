# Portfolio Terminal

Portfólio interativo em formato de terminal, feito com Angular 21 e Tailwind CSS 4.

```
visitante@portfolio:~$ help
visitante@portfolio:~$ visualizar-projeto portfolio-terminal
```

## Rodando

```bash
npm install
npm start          # http://localhost:4200
npm run test:ci    # testes unitários
npm run build      # build de produção (dist/portfolio-terminal/browser)
```

Detalhes de arquitetura, comandos e convenções: veja [CLAUDE.md](CLAUDE.md).
